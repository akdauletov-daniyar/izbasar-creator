# Избасар Мамыров — персональный сайт

Одностраничный сайт психолога, КПТ-терапевта и ICF-коуча. Тексты — из `context/context.md`,
визуальный язык — из [`design-system.md`](./design-system.md) (тёмная тема `#131516`,
акцент `#2D6A4F`, шрифты Unbounded + Inter).

## Стек

| Слой | Решение | Почему |
| --- | --- | --- |
| Фреймворк | **Next.js 15**, App Router | Статическая генерация всей страницы, оптимизация картинок, деплой в один клик |
| Язык | **TypeScript** (strict) | Контент типизирован — опечатка в ключе ломает сборку, а не продакшн |
| Стили | **Tailwind CSS v4** | CSS-first `@theme`: токены дизайн-системы объявлены один раз и работают и как утилиты, и как CSS-переменные |
| Шрифты | `next/font/google` | Unbounded и Interself-hosted на своём домене, без CLS, с сабсетами `cyrillic` + `cyrillic-ext` |

Страница целиком пререндерится (`○ Static`). Клиентский JS остался только там, где он нужен:
меню, модалка видео и поле имени в форме записи. Остальные секции — серверные компоненты.

| Поле | Что указать |

| `site.url` | боевой домен — используется в метаданных Open Graph и JSON-LD |

Уже подключено:

- **Видео** — `video.embedUrl` → `9SkViTOsVJ8`, автозапуск при открытии модалки.
- **WhatsApp** — `contacts.whatsapp` → `+7 700 338 9979`.

**Бэкенд не нужен.** Обе точки конверсии ведут в WhatsApp с готовым текстом:

- запись на консультацию — форма спрашивает только имя, кнопка неактивна, пока оно не введено;
- книга — одна кнопка, вводить ничего не нужно (`book.whatsappMessage`).

## Дизайн-система

`globals.css` — прямой порт [`design-system.md`](./design-system.md):

- `@theme` — цвета, шкала типографики, радиусы, тени, брейкпоинты (§2, §3, §5).
- `:root` — градиенты, скримы, контейнеры, длительности анимаций (§2.4, §4.2, §8).
- `@layer components` — `.btn-*`, `.card`, `.field`, `.icon-badge`, `.panel-hero` и остальные
  компоненты из §7.

Ключевое правило при доработках: **`#2D6A4F` — только заливка** (2.9 : 1 на фоне `#131516`).
Акцент как текст — `--color-accent-ink` (`#52B788`, 7.4 : 1) или утилита `.accent`.

## Деплой на Vercel

```bash
npx vercel
```

Настроек в дашборде не нужно — Vercel определит Next.js сам. Единственная переменная:

| Переменная | Значение | Где |
| --- | --- | --- |
| `NEXT_PUBLIC_SITE_URL` | `https://izbasar.kz` | Settings → Environment Variables → **Production** |

Без неё сайт возьмёт адрес деплоя из `VERCEL_URL` — работать будет, но `canonical`,
`og:image` и `sitemap.xml` укажут на технический домен `*.vercel.app`.

Что уже сделано под Vercel:

- `robots.txt` и `sitemap.xml` генерируются из адреса окружения (`src/app/robots.ts`,
  `src/app/sitemap.ts`). **Preview-деплои закрыты от индексации** — иначе они конкурируют
  с продакшном в выдаче.
- Заголовки безопасности и `Cache-Control: immutable` для `/images/*` — в `next.config.mjs`.
- `images.deviceSizes` сокращён до реальных точек макета: Vercel тарифицирует трансформации
  изображений поштучно, и лишние ширины — это лишние деньги.
- `.vercelignore` исключает `assets/`, `context/` и макет из загрузки.

Для статичной выгрузки на другой хостинг: `output: 'export'` в `next.config.mjs`
и `images.unoptimized = true` (тогда оптимизация картинок отключится).
